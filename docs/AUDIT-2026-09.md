# Stabilization audit — September 2026

A repository-wide review of Meno at `main` @ `25a4b7a`, carried out before the
second stabilization PR. Each finding is rated on two axes:

- **Severity** — user or developer impact if left alone (High / Medium / Low).
- **Fix risk** — how likely a fix is to regress behaviour or GUI feel
  (Low / Medium / High).

Status: **PR** = addressed in the stabilization PR that adds this document;
**#2** = covered by the open PR #2; **Open** = backlog / issue candidate.

Baseline at the time of the audit: `npm run build` passed, `npm run lint`
passed with 13 warnings, there were no frontend tests, and no CI. Rust could not
be compiled on the audit machine (no MSVC build tools), which is why Rust-side
findings are left open and are verified through CI instead.

## Correctness bugs

| ID | Finding | Sev | Risk | Status |
| --- | --- | --- | --- | --- |
| B1 | Format detection treats any file whose first line is an integer as XYZ, before looking for MOL markers. MOL/SDF files whose title line is a number — e.g. PubChem SDFs, which use the CID as the title — are routed to the 3D viewer and parsed as XYZ, producing garbage. Affects both `detectFormat` and OmniHub's own `isXyz`. | High | Low | PR |
| B2 | RXN reactant/product counts are read from the first header line containing two integers. A reaction name such as `step 1 of 2` is mistaken for the counts line, so molecules are assigned to the wrong side of the arrow. The CTfile spec fixes the counts line at line 5. | Medium | Low | PR |
| B3 | The 2D editor keeps a module-level store registry keyed by `tabId`. The workflow editor passes its React Flow node id (`"mol2d"`) as `tabId`, so **every Workflow Builder tab shares one sketch store**, and closing one tab deletes the registry entry the others still use. | High | Low | PR |
| B4 | Python console: event listeners are registered asynchronously inside an effect keyed on `pid`. Output emitted between spawn and re-subscription (e.g. the auto-run `AUTO OK`) is dropped, a fast cleanup can leak listeners (duplicated lines under React StrictMode), and a failed `Start` (missing `uv`, network error) gives no feedback. | Medium | Low | PR |
| B5 | `StructureCanvas` hardcodes `active={true}`, so every 2D tab keeps its render loop running at DPR ≥ 2 while hidden. The `active` flag already exists and the 3D viewer uses the same pattern. | Medium | Low | PR |
| B6 | `Bonds2D` sizes its instanced mesh for 3 segments per bond; hashed wedges and wavy bonds need more, overflowing the buffer and blanking the canvas. | High | Low | #2 |
| B7 | Rust: when a sidecar exits by itself its `Child` stays in `ProcState` and is never waited on (handle leak); running sidecars are not killed when the app exits. | Medium | Low | Open |
| B8 | MDL bond stereo code 3 ("cis/trans either" on double bonds) is mapped to a wavy single-bond depiction. Needs a chemistry decision (crossed double bond?). | Low | Medium | Open |
| B9 | Import failures only reach `console.warn`; the user sees nothing. `.pdb` and `.ket` are offered in the file picker but no parser exists. | Medium | Medium | Open |

## Security (Tauri commands and process execution)

| ID | Finding | Sev | Risk | Status |
| --- | --- | --- | --- | --- |
| S1 | `ext_spawn_sidecar` spawns **any absolute path with any arguments** passed from the webview. `py_env_setup_uv` executes a `uv` path supplied by the frontend and joins `venvHome` (which may contain `..`) onto the app data dir. Any script injection in the webview therefore becomes arbitrary command execution. Recommended: resolve executables and scripts in Rust from an enum (`profile`, `worker`) instead of accepting paths; reject `..`/absolute components. (The console runs arbitrary Python by design, so this is defense-in-depth, but it removes the easiest path.) | High | Medium | Open (needs Rust toolchain to verify) |
| S2 | `app.security.csp` is `null`. A CSP would limit the impact of any HTML/script injection. Needs GUI testing: motion/Tailwind use inline styles, textures may use `blob:`/`data:`. | Medium | Medium | Open |
| S3 | `Mutex::lock().unwrap()` in the sidecar commands turns a poisoned lock into a panic on every later call. | Low | Low | Open |
| S4 | File-system capabilities are scoped to `$RESOURCE` / `$APPDATA` / `$APPLOCALDATA`; no shell plugin is enabled. Reasonable as is. | — | — | OK |

## Architecture and coupling

| ID | Finding | Sev | Risk | Status |
| --- | --- | --- | --- | --- |
| A1 | Four parallel molecule type families: `utils/structureParsers` (`Molecule`), `utils/importers` (`EditorModel`), the editor store's `Atom`/`Bond`, and `lib/chem/layout2d`'s `Atom`/`Bond`. Conversions are ad hoc and use `as any`. Suggest one core chemistry model in `src/lib/chem`. | Medium | High | Open |
| A2 | Tab `content.data` is `unknown` and every view casts it with `as any`. A discriminated union per `TabKind` would make the registry type-safe. | Medium | Medium | Open |
| A3 | Duplicated code: `replayReplace`/`replayAppend` in `useStructureEvents`; `moleculesToEditorModel` re-implements `computeScaleForMols`; OmniHub re-implements format sniffing (removed by the B1 fix). | Low | Low | Partly PR |
| A4 | Frontend/backend contract is stringly typed: command names and payload shapes are repeated by hand, and events carry JSON encoded as a string. Suggest a single typed wrapper module (`src/lib/tauri/`) and typed event payloads. | Medium | Medium | Open |
| A5 | Python env logic is split: TypeScript computes lock hashes and stamp files, Rust runs `uv`. Moving it all to Rust would also fix S1. | Medium | Medium | Open |
| A6 | Very large components: `Atoms2D.tsx` (~1k lines), `GraphEditor.tsx` (~900 lines, six node types in one file). | Low | Medium | Open |
| A7 | Only the Windows `uv.exe` is bundled, so the Python features do not work on macOS/Linux. | Medium | Low | Open (documented in README) |

## Suggested issue order (after this PR and #2 land)

1. **S1 + A5** — Harden sidecar/uv commands: resolve paths in Rust from enums; reject traversal. Add Rust unit tests for path validation.
2. **B7 + S3** — Reap exited sidecars, kill children on app exit, avoid `unwrap()` on the process mutex.
3. **B9 + G1** — User-visible import errors (toast or inline message) and a visible "Open" action in the 2D editor.
4. **G5** — Decide a policy for inactive heavy views (unmount via `keepAlive: false`, or share one renderer).
5. **S2** — Introduce a CSP and verify every view renders.
6. **G2 + G3** — Tab bar polish: close on click, keyboard focus, clearer "New…" menu labels.
7. **A2 → A1** — Type tab data per kind, then converge on one chemistry model.
8. **G4** — Mark the workflow editor as a preview and persist node parameters in tab data.
9. **T4, B8, G6, G7, A6, D3** — Smaller clean-ups.
